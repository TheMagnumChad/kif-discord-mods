# Community Mods

Mods for KIF made by players. Install them in the game: **Options > Mods > Browse**.

**Made a mod?** See [CONTRIBUTING.md](CONTRIBUTING.md): add your mod's folder in a pull request, an automatic check looks it over, and once it's reviewed and merged it's in every player's Browse list.

Mods that were only shared on Discord are collected here too; their author is credited as "<author> (Imported from Discord)".
